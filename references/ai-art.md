# 用生图工具做一套新封面

本 Skill 不内置任何生图服务。用户当前环境里有什么生图能力（Agent 自带的生图、已安装的生图 Skill / MCP 工具等），就用什么；没有就走「没有生图工具」一节。

## 0. 先选出图方式

1. **环境里有生图工具**：直接用它，按下面的清单和提示词出图。生图会消耗用户额度或积分时，先说明要出几张（通常 2 张），用户同意再开始。
2. **用户自己有插画**：请对方把底图和各个元素发来（透明 PNG 最好；元素在一张图里也行，用第 3 节切开），然后第 4 节组装。
3. **都没有**：坦白说明，建议保留「冬夜月光」画面只改文字；或在本地用矢量 / 程序化绘制一套简化素材（画风会偏扁平，事先说清楚）。

不要替用户注册第三方服务、不要让用户贴 API Key、不要把用户的名字或祝福写进生图提示词。

## 1. 出图清单：通常只要 2 张

图越多，画风越容易跑偏。把所有前景元素放进**一张贴纸拼版**里一次画完，整套画风天然一致：

| 文件 | 内容 | 背景 | 建议尺寸 |
|---|---|---|---|
| `base.png` | 底图：奶白棉纸 + 双线压纹边框 + 中央拱形窗内远景，**不画任何前景大元素** | 满幅 | 竖幅 5:7 或 2:3（如 1024×1536）；比例接近时脚本缩放到 940×1316 并保留边框，差太多才裁剪 |
| `sheet.png` | 贴纸拼版：6–8 个前景元素分两三行排开，彼此留出明显空隙 | 纯品红 | 工具允许的最大正方或横幅（1536–2048 最好） |

拼版里放什么（按主题替换）：1 个主视觉（蛋糕 / 灯笼 / 礼盒）、2–3 个次要元素（花枝、礼物、气球）、1–2 朵云、1 个星芒、1 条横幅丝带、1 个圆形徽章。星星、云朵这类小件可以在 `theme.json` 里重复使用，不必多画。

只有两种情况才单独出图：某个元素在拼版里画坏了、或主视觉需要更高清。单独出的图也用纯品红底，组装脚本一样能识别。

## 2. 提示词模板

**两张都以同一段风格前缀开头**（把【主题】换成用户的场合，如「生日花园」「新春灯会」「毕业季」）：

> 风格前缀：分层纸雕贺卡元素，奶白冷压棉纸质感，纸张边缘有细微厚度，柔和漫射光，正面平视，无透视、无投影、无文字、无水印；配色柔和，暖金色 #CFA44E / #E6C97E 只用于局部烫金点缀；主题：【主题】。

底图：

> {风格前缀} 整张竖幅贺卡正面：奶白棉纸底，四周双线压纹边框和角花；中央一个拱形窗，窗内是【主题对应的远景，如暮色花园 / 夜空灯会】，颜色比纸面深，能衬托前景。窗外和窗下保持干净纸面，不画任何前景物体、不画卡片外轮廓。

贴纸拼版：

> {风格前缀} 一张贴纸拼版，在**纯品红色 #FF00FF 平涂背景**上分两到三行整齐排列以下独立元素，每个元素完整、互不接触、之间留出宽阔空隙：【主视觉】、【次要元素 1】、【次要元素 2】、【云朵】、【星芒】、【横幅丝带】、【圆形徽章】。背景无渐变、无阴影、无纹理，元素本身不使用品红色。

若生图工具支持透明背景输出，直接要透明 PNG 更好；画出了灰白棋盘格也能处理（脚本会自动识别）。

## 3. 切开拼版

```sh
python3 "$SKILL_DIR/scripts/split_sheet.py" ./work/sheet.png ./work/pieces
```

脚本按「从上到下、从左到右」输出 `piece-01.png`、`piece-02.png`…（已是透明背景），并生成带编号的总览图 `pieces/contact.png`。**先打开总览图看清每个编号是什么**，再写 `theme.json`。气球线、花茎这类细连接会保留在元素上，零星杂点会被丢弃；若元素被切碎或粘连，重新生成拼版并强调「互不接触、留宽空隙」。

## 4. 组装成卡片

1. 先用 `create_card.py` 生成卡片目录（已有目录就跳过）。
2. 在工作文件夹（不要放进 Skill 安装目录）里写 `theme.json`，`image` 指向切好的 `pieces/piece-NN.png`（或单独出的图）：

```json
{
  "base": "base.png",
  "items": [
    {"id": "cloud-left",  "image": "pieces/piece-04.png", "box": [70, 250, 230],  "lift": 0.010},
    {"id": "cloud-right", "image": "pieces/piece-04.png", "box": [660, 420, 200], "lift": 0.010},
    {"id": "star-right",  "image": "pieces/piece-05.png", "box": [772, 140, 92],  "lift": 0.012, "bob": 0.0012},
    {"id": "badge",       "image": "pieces/piece-07.png", "box": [400, 1000, 140], "lift": 0.012},
    {"id": "side-right",  "image": "pieces/piece-03.png", "box": [612, 640, 170], "lift": 0.020},
    {"id": "hero",        "image": "pieces/piece-01.png", "box": [320, 420, 300], "lift": 0.022},
    {"id": "side-left",   "image": "pieces/piece-02.png", "box": [70, 640, 290],  "lift": 0.024},
    {"id": "ribbon",      "image": "pieces/piece-06.png", "box": [150, 800, 640], "lift": 0.028}
  ],
  "motifs": [{"image": "pieces/piece-07.png", "px": 520}, {"image": "pieces/piece-05.png", "px": 320}],
  "backLine": "Happy Birthday",
  "glow": {"at": [470, 438], "color": "#ffcf7a", "size": 0.5, "intensity": 0.8, "flicker": true},
  "particles": {"kind": "petals", "area": [210, 170, 520, 560], "count": 30, "size": 0.15}
}
```

   - 坐标是 940×1316 封面像素：`box` 为 `[左, 上, 宽]`，高度按图片比例自动算。拱窗大约在 x 190–750、y 150–790。
   - `items` 按从远到近排列，`lift` 从 0.010 递增到 0.028；主视觉放窗内下半部，丝带压在窗框下沿，让部分元素破出窗框。
   - `glow` 放在烛火 / 灯光处；`particles` 的 `kind` 可选 `gold` / `petals` / `snow`；需要底图局部摆动时再加 `live`（见 [paper-art.md](paper-art.md) 第 4 节）。
3. 一条命令完成抠图、清理旧素材、合成平面封面和浮雕烫金烘焙：

```sh
python3 "$SKILL_DIR/scripts/assemble_theme.py" ./my-card ./work/theme.json
```

脚本先校验全部输入，有问题会指出哪一项并**不改动卡片**；成功后才替换 `art/`。

## 5. 看效果再微调

预览后按 [paper-art.md](paper-art.md) 第 5 节验收。位置不对就改 `theme.json` 的 `box` 重新运行；某个元素画坏了，只单独重出那一个元素，不必重做整张拼版。
